O topo mostra quanto a chance de uma recessão começar nos próximos 12 meses{% if estrutura.inicios|length > 3 %} ({{ estrutura.inicios[0] }} a {{ estrutura.inicios[3] }}){% endif %} está acima ou abaixo do normal. Recessão aqui é técnica: dois trimestres seguidos de queda do PIB, na série do IBGE. O normal é {{ normal|num }}%, a chance num ano comum pela história das recessões no Brasil (a âncora histórica). A conta de {{ data_curta(dia)[:5] }} dá {{ curto|num }}%, ou {{ mult_fmt }} o normal.{% if post %} O que mudou no dia está no post de {{ data_curta(dia)[:5] }}.{% endif %}

A pressão das notícias

As notícias não mexem no número. Elas mostram para que lado o risco está sendo empurrado, tema a tema, antes de os dados confirmarem. {% if pressao.sentido == 'sobe' %}Hoje, no conjunto, empurram para cima.{% elif pressao.sentido == 'desce' %}Hoje, no conjunto, aliviam.{% else %}Hoje, no conjunto, não empurram para um lado claro.{% endif %}

  • em cada tema, conta inteira a notícia mais forte de cada lado, metade da segunda, um quarto da terceira, e assim por diante: dez manchetes sobre o mesmo aperto não valem dez vezes uma;
  • o estágio pesa: dado divulgado e decisão tomada valem inteiros, proposta em votação vale pela chance de passar, anúncio vale {{ cfg.noticias.peso_por_estagio.anuncio|peso }} e rumor vale {{ cfg.noticias.peso_por_estagio.rumor|peso }};
  • cada notícia perde força em linha reta e some em {{ cfg.noticias.dias_de_decaimento }} dias;
  • a seta de um tema só aparece quando o saldo passa do corte publicado na metodologia.
